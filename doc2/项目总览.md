# 项目总览

## 项目介绍

**建筑施工质检情报员** — 面向建筑施工场景的 AI 驱动工单管理系统。单一 Next.js 代码库同时承载移动端（质检员/施工方）和 PC 端（管理员）前端及后端 API。

核心功能：工单流转平台 + AI Agent 对话助手。

## 用户角色与功能总览

| 角色 | 适用端 | 核心职责 |
|------|--------|----------|
| 质检员 | 移动端 | 发现问题，通过语音/图片发起报事；查询工单处理进度；查询施工规范知识。 |
| 施工方 | 移动端 | 被指派工单；反馈处理结果（解决/拒绝/指派他人）。 |
| 管理员 | PC 端 | 在后台查看全量工单，进行人工干预（强制指派/重新开启）。 |
| 所有角色 | 移动端 | 遇到不懂的施工工艺或规范时，通过对话框查询知识库。 |

## 路由结构

```
首页 / ：展示移动端和后台两个入口按钮
登录 /login ：进入后续任何界面未登录都会回到这里

移动端 /mobile/
  ├─ 智能助手 /mobile/assistant ：对话界面（知识检索、创建工单）
  ├─ 工单列表 /mobile/tickets ：工单 Tab 列表
  └─ 工单详情 /mobile/tickets/:id ：工单详情页

PC端 /dashboard/
  ├─ 数据大盘 /dashboard/overview ：统计概览
  ├─ 工单中心 /dashboard/tickets ：工单列表 + 筛选
  │   └─ 工单详情抽屉（右侧滑出）
  └─ 知识运营 /dashboard/knowledge ：候选池 + QA 对列表
```

## 技术栈

| 层次 | 技术选型 |
|------|----------|
| 框架 | Next.js 16 App Router（前后端一体化） |
| 数据库与鉴权 | Supabase（Postgres + Auth + RLS） |
| 主 Agent | LangChain `createAgent` |
| 知识 Agent | 扣子（Coze）平台外部 API |
| AI 总结 | Kimi API（单轮后端调用） |
| 流式响应 | LangChain `useStream` 处理 SSE |
| UI | Tailwind + shadcn/ui + lucide-react |
| 部署 | Vercel 一键部署 |

## 设计风格

- 简约专业的白底+浅蓝风格，类似 Notion 的界面感觉
- 保持平实，不用渐变、阴影堆叠、发光效果
- 全部界面使用中文
- Stitch 设计系统作为原型参考

## 不实现的功能（Demo 阶段）
