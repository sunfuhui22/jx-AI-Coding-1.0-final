# 移动端工单详情页

路径：`/mobile/tickets/:id`

## 页面内容

页面主体为 [工单详情组件](../核心组件/工单组件.md)，根据 URL 参数中的工单 ID 加载对应工单数据。

## 组件行为

- 默认以展示模式渲染工单信息
- 根据当前用户身份和工单状态，动态显示对应的操作按钮
- 编辑模式下底部显示"保存"按钮

## 导航

从 [工单列表页](工单列表页.md) 点击列表项进入，返回时回到列表页。
