# 移动端工单列表页

路径：`/mobile/tickets`

## 顶部 Tab 筛选

| Tab | 数据筛选 |
|-----|----------|
| 待处理（红点显示数量） | 状态 = 待处理 |
| 已结束 | 状态 = 已完成 + 已拒绝 |
| 全部 | 不筛选状态 |

## 按责任人筛选

| 筛选项 | 数据筛选 |
|--------|----------|
| 我负责的 | 当前用户为责任人 |
| 我提出的 | 当前用户为发起人 |
| 全部 | 不筛选 |

## 排序规则

- 默认按创建时间倒序
- 可切换为正序
- 严重程度为"紧急"的工单置顶并加红色边框

## 卡片项

工单卡片展示工单关键信息（问题描述、状态 Badge、严重程度、位置等），点击后跳转到 [工单详情页](工单详情页.md)。
如果有图片时，在卡片左侧展示预览
