# Agent 对话页

路径：`/mobile/assistant`

移动端智能助手页面，基于 Agent 的对话式 AI 交互界面。

## 页面组成

### 输入区
- **多模态输入**：点击"+"号面板，选择拍摄或相册上传图片。图片上传后返回 URL，作为上下文发送给 AI。
- **文本输入**：键盘手动输入文本。

### 消息流
- **AI 响应 Loading 态**：发送后连接后端 Agent stream，实时展示 Agent 操作流程。Agent 结束前禁止再次发送。
- **知识问答气泡**：Agent 回复文本内容时，以 Markdown 渲染到回答气泡中。
- **工单创建卡片**：Agent 返回 `create_ticket` tool_call 时，不显示纯文本，渲染工单卡片组件（表单可编辑，底部有"确认提交"按钮）。用户确认提交后前端调用创建工单 API，成功后自动向 Agent 发送包含工单 ID 的结构化信息。若存在该结构化消息，上一条消息中的工单卡片渲染为只读版本。

## 责任人选择

Agent 的 `create_ticket` tool_call 参数中不包含 `assignee` 字段。责任人需要用户在前端工单创建卡片中手动选择（必填，从当前项目的施工方用户中选择）。即使 Agent 能从对话上下文推断出责任人，也不会自动填入——保持 Agent 和前端职责的清晰分离。

## 页面框架

页面本身仅包含消息流 + 输入区布局，具体 Agent 交互逻辑见 Agent 模块文档。
