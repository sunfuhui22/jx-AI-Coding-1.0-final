# 工单创建 HITL Tool 定义

## 概述

主 Agent 识别到用户创建工单意图后，返回 `create_ticket` tool_call。Agent 不直接创建工单，而是通过 tool_call 通知前端渲染工单创建卡片，由用户确认并补充信息后，前端调用后端 API 完成实际创建。创建成功后，前端将结果返回给 Agent 继续对话。


## 前端渲染规则

### 工单创建卡片

当收到 `create_ticket` tool_call 时，前端渲染工单创建卡片组件（复用 [工单组件](../核心组件/工单组件.md) 的编辑模式）：

- 将 tool_call parameters 预填到工单创建表单各字段
- 额外增加「责任人」下拉选择（必填，从当前项目的施工方用户中选择）
- 用户可修改任何字段后再提交
- Agent 流式未完成前，提交按钮禁用
- 底部显示「确认提交」按钮

### 提交流程

1. 用户点击「确认提交」
2. 前端调用 `POST /api/tickets` 创建工单
3. 创建成功后将工单信息作为 tool_call result 返回给 Agent
4. Agent 回复须包含工单链接（Markdown 格式）
5. 前端将 HITL 结果持久化为 `[HITL_RESULT]` 消息

### 状态展示

- 未提交时：表单可编辑 + 提交按钮
- 提交成功后：卡片变为只读版本（无按钮），列表气泡展示"已提交"状态
- 提交失败：列表气泡展示"提交失败"

## 责任人选择

Agent 的 tool_call 参数中不包含 `assignee` 字段。责任人需要用户在前端手动选择（必填，从当前项目的施工方用户中选择）。即使 Agent 能从对话上下文中推断出责任人，也不会自动填入——这是为了保持 Agent 和前端职责的清晰分离，避免 Agent 误判导致工单错误指派。
