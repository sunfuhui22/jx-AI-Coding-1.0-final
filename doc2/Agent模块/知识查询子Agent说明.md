# 知识查询子 Agent 说明

## 概述

知识获取子 Agent 托管在外部平台（扣子 Coze），主 Agent 通过外部 API 调用。子 Agent 不直接与用户对话，只返回知识文本给主 Agent。

## 职责

在多种知识源中查询用户输入的主题，并返回详细的知识文本。支持多轮检索：信息不足时自动追加查询，而非一次返回。

## 入参

主 Agent 传入**精练的待查询主题**，而非直接复述用户原始提问。

### Query Rewriter 规则

- 在前序会话中已经检索清楚的主题不要再次传入
- 多个议题使用两个换行隔开
- 指代消解：将代词替换为具体实体名词
- 补全上下文：从前序对话中提取省略的背景信息
- 意图提纯：去除口语化前缀和语气词，保留核心检索词
- 不回答问题，只重构查询

### 示例

用户输入：「做学校设计的时候，该怎么设计门框和窗宽？要考虑哪些采光因素？」

主 Agent 传入：
```
学校建筑设计中门框、窗宽的设计尺寸要求，门窗数量设置原则

学校建筑设计中门窗设置对采光的影响
```

## 出参

子 Agent 返回最终文本给主 Agent，由主 Agent 整理后回复用户。不直接与用户交互。

## 实现要点

- 托管平台：扣子（Coze），具体 API 调用方式后期补充
- Agent 侧客户端：`lib/agent/coze-client.ts`（流式聚合最终 answer）
- 工具返回仅最终文本，前端卡片不展示原文
