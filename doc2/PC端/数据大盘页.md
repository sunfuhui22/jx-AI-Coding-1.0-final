# PC 端数据大盘

路径：`/dashboard/overview`

管理员视角的统计概览页面。

## 指标卡片

页面顶部展示以下统计指标卡片：

| 指标 | 说明 |
|------|------|
| 项目数量 | 当前系统中的项目总数 |
| 工单总数 | 全量工单数量 |
| 待处理工单 | 状态为待处理的工单数量 |
| 已完成工单 | 状态为已完成的工单数量 |
| 已拒绝工单 | 状态为已拒绝的工单数量 |
| 紧急工单 | 严重程度为紧急的工单数量 |

## 柱状图

指标卡片下方展示一个按严重程度分组的简单柱状图。
