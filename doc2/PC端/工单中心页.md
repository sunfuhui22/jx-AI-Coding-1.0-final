# PC 端工单中心

路径：`/dashboard/tickets`

管理员视角的工单管理页面，包含工单列表和详情抽屉。

## 工单列表

### 高级筛选

| 筛选项 | 控件 | 说明 |
|--------|------|------|
| 项目名称 | 下拉选择 | 按项目筛选 |
| 工单状态 | 多选 | 待处理 / 已完成 / 已拒绝 |
| 严重程度 | 多选 | 轻微 / 一般 / 严重 / 紧急 |
| 专业类型 | 下拉选择 | 建筑设计专业 / 结构专业 / 给排水专业 |
| 关键词搜索 | 文本输入 | 搜索"问题描述"或"工单编号" |

### 数据表格

| 列名 | 说明 |
|------|------|
| 工单编号 | 点击可跳转详情 |
| 状态 | Badge 徽标：🔴待处理 / 🟢已完成 / ⚪已拒绝 |
| 严重程度 | 若为"紧急"，整行浅红背景标记 |
| 项目 | [项目组件](../核心组件/用户组件.md#项目展示小组件) |
| 专业类型 | 文本 |
| 问题描述 | 截断显示（前20字…） |
| 创建时间 | YYYY-MM-DD HH:mm |
| 当前责任人 | 用户组件 |
| 发起人 | 用户组件 |
| 操作 | [查看详情] 按钮 |

## 工单详情抽屉

点击列表项或"查看详情"按钮，从右侧滑出抽屉，展示 [工单详情组件](../核心组件/工单组件.md)。
